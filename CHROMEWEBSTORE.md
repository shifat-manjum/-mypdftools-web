## 3. Privacy & Justifications Tab

### Single Purpose
```text
Captures full-page screenshots of webpages with privacy redaction and exports them as PNG or PDF documents.
```

### Permissions Justification (Copy & Paste)

| Permission | Justification |
| :--- | :--- |
| **`activeTab`** | Used exclusively to capture the visible tab viewport when the user actively triggers a screenshot via the popup button or keyboard shortcut. |
| **`scripting`** | Used to inject a scrolling script into the active tab to automatically scroll and capture long web pages from top to bottom. |
| **`storage`** | Used solely in browser local storage to hold the captured image slices temporarily so the preview studio can stitch, redact, and export them. |
